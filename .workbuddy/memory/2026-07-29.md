## 关机功能 + OOBE 修复 + 版权声明清理（已推送到 GitHub）

### 关机功能
- aarch64 内核**缺失 `arch_poweroff()`**（`syscall.c:1175` 调用但未定义，会导致链接失败且关机不可用）。已在 `kernel/arch/aarch64/arch.c` 实现（PSCI SYSTEM_OFF 0x84000008 + semihosting 回退），并在 `base/usr/include/kernel/misc.h` 声明。
- x86_64 `arch_poweroff()` 增强：在 `base/usr/include/kernel/arch/x86_64/acpi.h` 新增 `struct fadt`，在 `kernel/arch/x86_64/user.c` 实现基于 FADT 解析 PM1a 控制端口 + DSDT `_S5` 解析 S5 SLP_TYP 的真实 ACPI 关机，保留 QEMU 0x604 / 兼容 0xB004 / 键盘复位 回退。注意：`acpi_checksum` 不能直接用于 RSDP（v1 无 length 字段），已单独做 20 字节校验和。

### OOBE 首启动修复（核心 bug）
- 根因：`apps/live-session.c` 无条件以 local(UID 1000) 自动登录，且无 OOBE 检查；OOBE 触发逻辑只在 `apps/glogin.c` 中，而 live-session 在其后（注销后）才运行 glogin。导致"进入即 local / 注销才 OOBE / OOBE 后仍 local"。
- 修复：`live-session.c` 启动时先 `access("/etc/oobe_complete")` 检查，未完成则 fork 运行 `/bin/oobe`，完成后（或本来就已完成）一律交棒 `/bin/glogin`（不再自动登录 local）。`glogin-provider.c` 本身不会预填 local，故登录屏留空由用户选账户。保留了 yutani_init 的 dummy 连接防止 compositor 自杀。
